# Gestor de Tareas y Requerimientos de Soporte

Aplicación web para gestionar y hacer seguimiento de tareas y requerimientos de soporte técnico, con dashboard de métricas y sincronización en tiempo real con Google Sheets.

## Funcionalidades

- **Registro de requerimientos**: formulario con cliente, ciudad, plataforma, indicador, tipo y descripción
- **AI AutoFill**: pega un mensaje de WhatsApp y la IA detecta automáticamente los campos
- **Dashboard de métricas**: gráficos en tiempo real con Chart.js (por plataforma, estado, tipo)
- **Historial de tareas**: tabla filtrable y exportable a Excel (.xlsx)
- **Importación de clientes**: carga masiva desde Excel
- **Sincronización con Google Sheets**: base de datos en la nube vía Google Apps Script
- **Búsqueda inteligente**: dropdowns con búsqueda en tiempo real

## Stack tecnológico

- HTML5 + JavaScript (vanilla)
- Tailwind CSS, Chart.js, SheetJS, FontAwesome
- Google Apps Script + Google Sheets como backend

## Uso

Abre el archivo HTML directamente en tu navegador — no requiere instalación ni servidor.
